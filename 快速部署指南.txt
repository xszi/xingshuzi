═══ 准备工作（仅首次需要）═══

1. SSH登录ECS
   ssh root@120.76.247.123

2. 安装Docker和Docker Compose
   curl -fsSL https://get.docker.com | sh
   systemctl start docker
   systemctl enable docker

3. 安装Git
   apt update
   apt install git -y
   git --version

4. 配置Git SSH密钥（私有仓库需要）
   ssh-keygen -t rsa -b 4096 -C "your.email@example.com"
   cat ~/.ssh/id_rsa.pub
   # 复制公钥，添加到GitHub/Gitee的SSH Keys

═══ 首次部署 ═══

1. 克隆代码仓库
   cd /root
   git clone git@github.com:your-username/xingshuzi.git
   # 或HTTPS: git clone https://github.com/your-username/xingshuzi.git
   cd xingshuzi

2. 部署Flask后端
   cd /root/xingshuzi/server
   cp .env.example .env
   chmod +x deploy.sh
   ./deploy.sh

3. 验证后端
   curl http://localhost:5001/api/home/banners
   # 应返回: {"code":200,"data":[],"msg":"success"}

4. 部署Nuxt前端（需5-10分钟）
   cd /root/xingshuzi/web
   chmod +x deploy.sh
   ./deploy.sh

5. 验证前端
   curl -I http://localhost:3000
   # 应返回: HTTP/1.1 200 OK

═══ 更新部署（使用Git）═══

1. 拉取最新代码
   cd /root/xingshuzi
   git pull origin main

2. 更新后端（如果后端有变更）
   cd server
   ./deploy.sh

3. 更新前端（如果前端有变更）
   cd web
   ./deploy.sh

🔐 Git SSH密钥配置步骤
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. 在ECS上生成SSH密钥
   ssh-keygen -t rsa -b 4096 -C "your.email@example.com"
   # 按回车使用默认路径

2. 查看公钥
   cat ~/.ssh/id_rsa.pub

3. 复制公钥内容

4. 添加到Git平台
   GitHub: Settings → SSH and GPG keys → New SSH key
   Gitee:  设置 → SSH公钥 → 添加公钥

5. 测试连接
   ssh -T git@github.com
   # 或: ssh -T git@gitee.com

🐛 常见问题
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Q: Git克隆失败？
A: 检查网络: ping github.com
   检查SSH: ssh -T git@github.com
   使用HTTPS: git clone https://github.com/user/repo.git

Q: Permission denied (publickey)？
A: SSH密钥未配置或未添加到Git平台
   重新生成并添加公钥

Q: 代码更新后未生效？
A: 确保git pull成功
   重新构建: docker compose build --no-cache
   重新部署: ./deploy.sh

Q: 端口被占用？
A: 检查端口: netstat -tlnp | grep 5001
   停止旧容器: docker compose down
